## 手工验收建议

- 授权后先发送 TEST 邮件，核对主题中的成员名称／ID、附件 UTF-8 中文、正文与附件一致。
- 连续做两笔同金额的付款，核对两条都保留；重复通知应不新增事件。
- 锁屏支付后核对记录；不要将零记录理解成零消费。
- 断网到发送时间，恢复网络后核对只新增一个正常日报批次。
- 发送中断后出现“结果不确定”时，先检查邮箱再手动重试，核对原批次 ID 未变化。
- 恢复默认省电策略观察一天；只有发现明显漏采／延迟才开启厂商后台豁免。

常驻模式验收：对比两种模式各 24–48 小时的电量与漏采；从通知切回静默后确认仍可采集；重启解锁后检查恢复，强行停止后重新打开。常驻不承诺进程永不被回收。
